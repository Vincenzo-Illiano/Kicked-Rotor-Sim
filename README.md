# Classical Kicked Rotor

Vincenzo Illiano · PAF project supervised by Prof. F. Dalfovo, 2025/26

This project studies the dynamics of a classical rotor subject to periodic kicks. The report derives the Chirikov standard map, then uses phase-space plots and finite-time Lyapunov estimates to explore regular and chaotic motion as the kick strength varies.
